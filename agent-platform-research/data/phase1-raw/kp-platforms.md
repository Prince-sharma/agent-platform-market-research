## Notes
- Every major model vendor now ships a first-party agent stack (OpenAI AgentKit, Anthropic Agent SDK, Google ADK, AWS Strands, Microsoft Agent Framework merging SK and AutoGen, Cohere North); agent building has become a table-stakes model-vendor feature.
- Agentic workflow automation is the best-funded L2 niche in 2025-26: n8n reached a $5.2B valuation after SAP's strategic investment (May 2026), and Gumloop ($50M Benchmark), Dust ($40M), CopilotKit ($27M), Mastra ($22M), and Dify ($30M) all raised in 2026.
- An exit wave cleared early movers: Respell to Salesforce, Cognigy to NiCE (~$955M), Amelia to SoundHound ($80M after $189M raised), Langflow to IBM via DataStax; Yellow.ai announced a ~$550M SPAC listing (Aug 2026).
- China runs a parallel L2 ecosystem (Coze, Dify, HiAgent, Tencent Yuanqi, JoyAgent, Baidu AgentBuilder) that open-sourced aggressively in 2025 (Coze Studio, JoyAgent JDGenie) but shows little Western enterprise penetration.
- The conversational-AI incumbents diverged sharply: Kore.ai (Artemis launch, Gartner MQ Leader 2026, AllianceBernstein investment) and Rasa (Deutsche Telekom, Autodesk, Swisscom) are scaling while Amelia exited cheaply.
- Adjacent L1 infrastructure (agent security, tool vetting, memory, observability) is drawing large rounds (AIR $50M and Sapiom $35M in Aug-Sep 2026), and the L2/L1 boundary is blurring, with Letta shipping memory plus an agent framework.
