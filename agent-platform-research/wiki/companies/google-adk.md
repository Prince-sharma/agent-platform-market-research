## The eleven build decisions

1. **Build interface:** code and config workflow with a visual builder option
2. **Runtime and tenancy:** vendor multi-tenant SaaS (Cloud Run, GKE) or self-host
3. **Tool and integration strategy:** MCP, OpenAPI tools, and proprietary connector library
4. **Knowledge and data strategy:** built-in RAG via Google Search Grounding and model context caching
5. **Autonomy and human-in-the-loop:** approval gates via action confirmations and human input in graph workflows
6. **Governance and enterprise controls:** RBAC, audit trails, and safety and security components
7. **Pricing model:** unknown
8. **GTM motion:** PLG self-serve via open-source and Google Cloud distribution
9. **Moat thesis:** distribution via Google Cloud and deep Gemini model integration
10. **Open-source posture:** OSS core; self-host option
11. **Task horizon:** multi-step workflow (minutes) to persistent (always-on) ambient agents
