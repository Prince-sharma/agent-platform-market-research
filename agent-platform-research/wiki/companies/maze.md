**Thesis (one line):** Maze uses AI agents to investigate and resolve cloud security vulnerabilities by identifying truly exploitable threats across code and infrastructure.

## Analysis

- **Agent capability depth:** Agents perform end-to-end vulnerability management by investigating every environment vulnerability to check for technical exploitation requirements. They triage CVEs in containers, VMs, and third-party code, and identify business-logic vulnerabilities.
- **Weaknesses:** Initial focus was heavily weighted toward triage and investigation, with remediation capabilities being developed as a subsequent step.
- **Trajectory:** Expanding agent capabilities into new use cases for its AI-native security platform.
- **M&A:** none visible
