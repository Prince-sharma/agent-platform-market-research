# Nozomio

**Thesis (one line):** A context layer that indexes codebases and documentation to provide grounded, hallucination-free context for AI coding agents.

## Facts

- Founded: 2025
- HQ: San Francisco
- YC batch: S25
- Backers: Y Combinator, LocalGlobe, AGI house
- Funding: $15.2M total
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Developers using AI coding agents (e.g., Cursor, Claude Code)
- Pricing model: unknown

## The eleven build decisions

1. **Build interface:** Dashboard and integration with MCP clients
2. **Runtime and tenancy:** unknown
3. **Tool and integration strategy:** MCP (Model Context Protocol)
4. **Knowledge and data strategy:** Built-in RAG indexing for docs, repos, PDFs, and datasets
5. **Autonomy and human-in-the-loop:** unknown
6. **Governance and enterprise controls:** unknown
7. **Pricing model:** unknown
8. **GTM motion:** PLG self-serve
9. **Moat thesis:** Data gravity via indexing diverse codebase and documentation sources
10. **Open-source posture:** Proprietary (with a public GitHub repository for the Nia project)
11. **Task horizon:** Single-turn to multi-step workflow (providing context for agent queries)

## Analysis

- **Agent capability depth:** Enables coding agents to query real-time, indexed documentation and repositories to eliminate hallucinations.
- **Weaknesses:** Early stage with limited visible enterprise governance features.
- **Trajectory:** Expanding from a coding-specific context layer (Nia) into a broader "product lab" for personal AI and context.
- **M&A:** none visible
