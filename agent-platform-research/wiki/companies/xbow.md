# XBOW

**Thesis (one line):** An autonomous AI pentesting agent that discovers and validates software vulnerabilities at machine speed to outpace modern attackers.

## Facts

- Founded: unknown
- HQ: Seattle, WA
- YC batch: none
- Backers: DFJ Growth (lead), Northzone (lead), Sofina, Alkeon Capital, Altimeter, NFDG Ventures, Sequoia Capital
- Funding: $237M total; $120M Series C (Mar 2026)
- Valuation: Over $1B (Mar 2026)
- Revenue/ARR: unknown
- ICP: Security teams and enterprises requiring continuous offensive security testing
- Pricing model: Usage-based per test

## The eleven build decisions

1. **Build interface:** Web-based self-service (Pentest On-Demand); users point the agent at a URL.
2. **Runtime and tenancy:** Vendor SaaS; available via AWS, Google, Oracle, and Microsoft marketplaces.
3. **Tool and integration strategy:** Proprietary autonomous platform that explores applications and APIs.
4. **Knowledge and data strategy:** unknown
5. **Autonomy and human-in-the-loop:** Fully autonomous discovery and validation; delivers results without scoping calls or kickoff meetings.
6. **Governance and enterprise controls:** Enterprise tier includes SSO, API access, and reports positioned for SOC 2 and ISO compliance.
7. **Pricing model:** Per test: $4,000 (Lightspeed Plus for lightweight apps), $8,000 (Lightspeed Premium for complex apps), or custom Enterprise quote.
8. **GTM motion:** Hybrid; PLG self-service (Pentest On-Demand) and sales-led Enterprise quotes.
9. **Moat thesis:** Performance evals (ranked #1 on HackerOne and Microsoft MSRC leaderboard) and real exploit validation.
10. **Open-source posture:** Proprietary.
11. **Task horizon:** Multi-step workflow; delivers expert-level results within five business days.

## Analysis

- **Agent capability depth:** The agent autonomously probes systems, reasons through complex exploit paths, and chains vulnerabilities. It does not just surface findings but provides proof-of-concept exploits and remediation.
- **Weaknesses:** Does not currently maintain a formal bug bounty or structured vulnerability disclosure program.
- **Trajectory:** Scaling from point-in-time tests to continuous coverage and international expansion using Series C funding.
- **M&A:** none visible
