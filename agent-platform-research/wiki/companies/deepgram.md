## Analysis

- **Agent capability depth:** Provides the foundational modality layer (STT, TTS, and Voice Agent API) for real-time conversational AI, including turn detection and interruption handling.
- **Weaknesses:** Primarily a model provider rather than a full-stack agent orchestration platform.
- **Trajectory:** Expanding from a speech-to-text provider into a comprehensive "Voice AI economy" API platform.
- **M&A:** Acquired OfOne (January 2026) to expand into restaurant voice automation.
