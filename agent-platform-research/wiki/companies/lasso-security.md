# Lasso Security

**Thesis (one line):** An AI security platform providing runtime guardrails and intent-based protection to secure enterprise AI agents and applications.

## Facts

- Founded: 2023
- HQ: Tel Aviv, Israel
- YC batch: none
- Backers: ClearSky (lead), Entrée Capital, iAngels, Singtel Innov8, Mindset, Swish Data
- Funding: $37M+ total; $30M last round (2026-09-02)
- Valuation: unknown
- Revenue/ARR: 500% revenue growth in past 12 months (reported 2026-09-03)
- ICP: Enterprise security teams and AppSec teams securing AI agents and LLM applications.
- Pricing model: Custom enterprise quotes (no self-serve)

## The eleven build decisions

1. **Build interface:** Inline LLM API gateway and platform dashboard for discovery and risk assessment.
2. **Runtime and tenancy:** unknown
3. **Tool and integration strategy:** Supports MCP servers, Microsoft Copilot, Salesforce Agentforce, and Claude Agent SDK.
4. **Knowledge and data strategy:** Intent baseline framework to analyze the "why" behind agent interactions.
5. **Autonomy and human-in-the-loop:** Enforces real-time guardrails to block prompt injections and data leaks.
6. **Governance and enterprise controls:** AI governance, risk assessment, and compliance mapping (EU AI Act, NIST).
7. **Pricing model:** Custom enterprise pricing; reported as annual commit plus per-unit charges.
8. **GTM motion:** Sales-led enterprise motion.
9. **Moat thesis:** Performance and cost efficiency via LEAP (transformer-free, CPU-only guardrails with <5ms latency).
10. **Open-source posture:** Proprietary.
11. **Task horizon:** Persistent (always-on runtime protection).

## Analysis

- **Agent capability depth:** Enables agents to operate with higher agency by providing a safety layer that detects goal hijacking, memory poisoning, and tool misuse.
- **Weaknesses:** Lack of pricing transparency and no free trial or self-serve tier may hinder adoption among smaller developers.
- **Trajectory:** Moving toward high-efficiency, low-latency security infrastructure to remove the "GPU tax" associated with AI safety.
- **M&A:** none visible
