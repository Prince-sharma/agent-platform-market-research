# Greptile

**Thesis (one line):** An AI code review and validation layer that uses codebase context and runtime execution to catch bugs before deployment.

## Facts

- Founded: 2023
- HQ: San Francisco, CA
- YC batch: W24
- Backers: Benchmark (lead), Initialized Capital, YC, Cory Levy
- Funding: $25M Series A (2025-09-23)
- Valuation: $180M (reported 2025-07-18, terms may have changed)
- Revenue/ARR: unknown
- ICP: Software engineering teams and organizations at scale
- Pricing model: Per active developer seat with credit-based usage

## The eleven build decisions

1. **Build interface:** AI code review agent (PRs), IDE integration via MCP
2. **Runtime and tenancy:** Multi-tenant cloud or self-hosted in customer infrastructure
3. **Tool and integration strategy:** Integrations with GitHub (including Enterprise), Jira, and Notion
4. **Knowledge and data strategy:** Graph-based context of repository (functions, classes, imports, dependencies); learns from GitHub comments
5. **Autonomy and human-in-the-loop:** AI agent reviews PRs; developers address or reply to comments
6. **Governance and enterprise controls:** SOC 2, SSO/SAML, security and governance controls
7. **Pricing model:** Starter (Free); Pro ($30/seat/month including 50 credits); Enterprise (Custom). Flex usage at $1/additional credit.
8. **GTM motion:** PLG self-serve (14-day free trial) and sales-led for Enterprise
9. **Moat thesis:** Deep codebase understanding via repository graphs and runtime validation (T-Rex)
10. **Open-source posture:** Proprietary; offers self-host option for Enterprise
11. **Task horizon:** Multi-step workflow (reviewing PRs, writing and running targeted tests in sandbox)

## Analysis

- **Agent capability depth:** The agent performs full codebase context reviews to detect cross-file inconsistencies and ripple effects. Through "T-Rex," it can write and execute targeted tests in a sandboxed environment to catch runtime bugs.
- **Weaknesses:** unknown
- **Trajectory:** Moving toward a "universal code validation layer" to handle the increase in code volume generated by other AI coding agents.
- **M&A:** none visible
