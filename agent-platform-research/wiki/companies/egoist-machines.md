# Egoist Machines

**Thesis (one line):** A user-owned, portable context layer allowing individuals to carry preferences and identity across different AI applications securely.

## Facts

- Founded: unknown
- HQ: San Francisco
- YC batch: S26
- Backers: Y Combinator
- Funding: unknown
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Consumer-facing AI applications and their users
- Pricing model: Free for life (for users)

## The eleven build decisions

1. **Build interface:** Dashboard for users to claim handles and manage permissions; unknown for developers.
2. **Runtime and tenancy:** multi-tenant SaaS
3. **Tool and integration strategy:** Proprietary connectors to link AI assistants and apps.
4. **Knowledge and data strategy:** User-owned memory layer that stores preferences, history, and identity.
5. **Autonomy and human-in-the-loop:** High; users review preferences and context before they are shared.
6. **Governance and enterprise controls:** Audit receipts showing what data was used; user-controlled access permissions.
7. **Pricing model:** unknown
8. **GTM motion:** PLG self-serve
9. **Moat thesis:** Data gravity via a portable, universal user identity and memory layer.
10. **Open-source posture:** proprietary
11. **Task horizon:** persistent (always-on context)

## Analysis

- **Agent capability depth:** Enables agents to have immediate, hyper-personalized context without requiring the user to re-explain themselves.
- **Weaknesses:** Dependent on third-party AI apps adopting the AI Passport standard to be useful.
- **Trajectory:** Moving toward becoming the "Web 4.0" infrastructure for user-owned personalization.
- **M&A:** none visible
