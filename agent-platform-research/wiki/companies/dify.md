## The eleven build decisions

1. **Build interface:** drag-and-drop canvas (Workflow Studio Visual Builder) and natural language configuration.
2. **Runtime and tenancy:** vendor multi-tenant SaaS, dedicated VPC, and self-host (Docker/K8s).
3. **Tool and integration strategy:** Marketplace for tools and models, including MCP integrations.
4. **Knowledge and data strategy:** built-in RAG with a dedicated Knowledge Pipeline for extraction, cleaning, and indexing.
5. **Autonomy and human-in-the-loop:** fixed workflow with support for human input nodes.
6. **Governance and enterprise controls:** RBAC, audit logs, SSO/SAML, SOC 2 Type II, and ISO 27001.
7. **Pricing model:** platform fee per workspace with included message credits and storage quotas.
8. **GTM motion:** PLG self-serve (Cloud/Community) and sales-led (Enterprise).
9. **Moat thesis:** open-source distribution and workflow lock-in via visual orchestration.
10. **Open-source posture:** OSS core (Apache-2.0-derivative); self-host option available.
11. **Task horizon:** multi-step workflow (minutes).
