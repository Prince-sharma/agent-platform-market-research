**Thesis (one line):** Infrastructure providing a unified API and MCP server to give AI agents real-world geographic, environmental, and demographic context.

1. **Build interface:** Code-first via API and MCP server
2. **Runtime and tenancy:** unknown
3. **Tool and integration strategy:** MCP (Model Context Protocol)
4. **Knowledge and data strategy:** Live sync/aggregation of federal and third-party data sources (USGS, FEMA, NOAA, etc.)
5. **Autonomy and human-in-the-loop:** unknown
6. **Governance and enterprise controls:** unknown

- **Weaknesses:** Currently focused primarily on US-based data sources.
