# Zoho Zia

**Thesis (one line):** An L5 agentic suite integrating autonomous agents across 100+ Zoho apps via a unified data model and no-code studio.

## Facts

- Founded: 1996
- HQ: Austin, Texas
- YC batch: none
- Backers: unknown
- Funding: private company
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Enterprises using the Zoho product ecosystem
- Pricing model: unknown

## The eleven build decisions

1. **Build interface:** no-code and low-code (Zia Agent Studio)
2. **Runtime and tenancy:** vendor multi-tenant SaaS
3. **Tool and integration strategy:** MCP server; proprietary connector library (Zoho ecosystem)
4. **Knowledge and data strategy:** live sync with systems of record (unified data platform/shared data model)
5. **Autonomy and human-in-the-loop:** fully autonomous (evolved from copilot to autopilot)
6. **Governance and enterprise controls:** RBAC, audit trails, compliance certs (proprietary tech stack/data centers)
7. **Pricing model:** unknown (no published rates; CEO publicly opposed premium agent pricing)
8. **GTM motion:** bundle/distribution (installed base of 850,000+ businesses)
9. **Moat thesis:** data gravity (shared data model), distribution, infrastructure ownership
10. **Open-source posture:** proprietary
11. **Task horizon:** multi-step workflow (minutes)

## Analysis

- **Agent capability depth:** End-to-end automation of functional roles (SDR, HR, IT Help Desk, Account Manager) across the 55-app suite.
- **Weaknesses:** Heavy dependency on the Zoho ecosystem for maximum utility.
- **Trajectory:** Moving toward "commodity reasoning" by owning the full stack (LLMs and data centers) to lower TCO.
- **M&A:** none visible
