# Google Agentspace

**Thesis (one line):** Google's enterprise agent platform integrating no-code building, A2A interoperability, and deep Workspace/Cloud ecosystem distribution.

## Facts

- Founded: unknown
- HQ: Mountain View, CA
- YC batch: none
- Backers: public company (GOOGL)
- Funding: public company (GOOGL)
- Valuation: unknown
- Revenue/ARR: unknown (Gemini Enterprise priced at $30 per seat, 2026)
- ICP: Enterprise organizations using Google Workspace or Google Cloud
- Pricing model: per seat

## The eleven build decisions

1. **Build interface:** drag-and-drop canvas / natural language
2. **Runtime and tenancy:** vendor multi-tenant SaaS
3. **Tool and integration strategy:** proprietary connector library / MCP / A2A protocol
4. **Knowledge and data strategy:** built-in RAG / live sync with systems of record
5. **Autonomy and human-in-the-loop:** approval gates; guardrails
6. **Governance and enterprise controls:** RBAC, audit trails, compliance certs, agent identity, spend caps
7. **Pricing model:** per seat
8. **GTM motion:** sales-led / bundle with Gemini Enterprise
9. **Moat thesis:** distribution, data gravity
10. **Open-source posture:** proprietary; OSS framework (Agent Development Kit)
11. **Task horizon:** multi-step workflow (minutes) / persistent (always-on)

## Analysis

- **Agent capability depth:** Enables creation of single and multi-step agents with subagents for complex task orchestration, grounded in enterprise data.
- **Weaknesses:** unknown
- **Trajectory:** Transitioned from standalone Agentspace to a core component of the unified Gemini Enterprise platform (Oct 2025 - April 2026).
- **M&A:** none visible
