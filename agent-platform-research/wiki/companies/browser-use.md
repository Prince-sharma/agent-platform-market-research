# Browser Use

**Thesis (one line):** An open-source framework and infrastructure layer enabling AI agents to navigate and interact with the web via structured text.

## Facts

- Founded: unknown
- HQ: unknown
- YC batch: YC W25
- Backers: Felicis (lead), A Capital, Nexus Ventures, Paul Graham, Liquid2, SV Angel, Pioneer Fund
- Funding: $17M seed (2025-03-22)
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: AI developers and agent framework builders
- Pricing model: Usage-based credits (dollar-denominated)

## The eleven build decisions

1. **Build interface:** code (Python library) and natural language (API V4)
2. **Runtime and tenancy:** vendor multi-tenant SaaS (Cloud) and self-host (OSS library)
3. **Tool and integration strategy:** MCP and SDK
4. **Knowledge and data strategy:** live sync with systems of record (browser-based)
5. **Autonomy and human-in-the-loop:** fully autonomous; guardrails unknown
6. **Governance and enterprise controls:** spend caps (via credit balance)
7. **Pricing model:** platform fee plus usage (browser-hours and network traffic)
8. **GTM motion:** PLG self-serve (OSS and Free Tier)
9. **Moat thesis:** distribution (OSS stars) and price (low-cost infrastructure)
10. **Open-source posture:** OSS core; self-host option
11. **Task horizon:** multi-step workflow (minutes)

## Analysis

- **Agent capability depth:** Converts website interfaces into structured text for LLMs to perform deterministic navigation, form filling, and data extraction.
- **Weaknesses:** Dependency on LLM's ability to interpret structured text representations of DOMs.
- **Trajectory:** Moving from a pure library to a comprehensive infrastructure layer (Browser Use Cloud) providing managed remote browsers.
- **M&A:** none visible
