# Daytona

**Thesis (one line):** Open-source sandbox runtimes provisioned in ~90ms for AI-generated code and agents; agent-native compute infrastructure.

## Facts

- Founded: 2023 (Daytona Platforms Inc)
- HQ: New York, NY
- YC batch: none
- Backers: FirstMark (Series A lead, Feb 2026) with Pace Capital, Upfront, E2VC, Darkmode, Datadog, Figma Ventures
- Funding: ~$26M: $2M pre-seed (Nov 2023) plus $24M Series A (Feb 5, 2026)
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: AI and agent-platform engineering teams needing sandboxed code execution
- Pricing model: Usage-based ($0.0504/vCPU-hr Linux, $0.0858 Windows, RAM $0.0162/GiB-hr; $200 free credits)

## The eleven build decisions

1. **Build interface:** Code (SDK/API) plus dashboard
2. **Runtime and tenancy:** Multi-tenant SaaS plus self-host (OSS); enterprise via sales
3. **Tool and integration strategy:** SDK/API-first; MCP support unknown
4. **Knowledge and data strategy:** Infrastructure; no RAG
5. **Autonomy and human-in-the-loop:** Infrastructure; not applicable
6. **Governance and enterprise controls:** SOC 2 Type I and II (Apr 2026), HIPAA, GDPR, ISO 27001
7. **Pricing model:** Pure usage-based compute metering with free credits
8. **GTM motion:** PLG (free credits) plus sales-led enterprise
9. **Moat thesis:** 90ms sandbox startup speed, OSS distribution, compliance depth
10. **Open-source posture:** OSS core (github.com/daytonaio/daytona); self-host option
11. **Task horizon:** Long-horizon stateful, long-running agent workloads

## Analysis

- **Agent capability depth:** Instantly provisioned, isolated, stateful sandbox runtimes ("composable computers") for agents to execute code and long-running workloads
- **Weaknesses:** Small team (33 employees, Jun 2026); crowded sandbox market (E2B, Modal, cloud vendors)
- **Trajectory:** From self-hosted dev-environment manager (2023) to agent-native compute infrastructure (Series A thesis, Feb 2026)
- **M&A:** None visible
