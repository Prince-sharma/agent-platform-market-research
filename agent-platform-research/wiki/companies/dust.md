## The eleven build decisions

1. **Build interface:** Natural language and configuration via agent and skill creation
2. **Runtime and tenancy:** Vendor multi-tenant SaaS
3. **Tool and integration strategy:** MCP (Client Side MCP Server in preview) and proprietary connections
4. **Knowledge and data strategy:** Built-in RAG connecting agents to internal company data
5. **Autonomy and human-in-the-loop:** Shared human-agent collaboration surface with "multiplayer" interaction
6. **Governance and enterprise controls:** RBAC (members and roles), audit logs, and admin controls for spaces and agents
7. **Pricing model:** Seats and credits
8. **GTM motion:** unknown
9. **Moat thesis:** Data gravity through internal knowledge integration and workflow lock-in via specialized agent teams
10. **Open-source posture:** Proprietary
11. **Task horizon:** Multi-step workflow via specialized agents and skills
