# Hoplite

**Thesis (one line):** A development platform that provides isolated cloud environments for AI coding agents to execute tasks and ship pull requests.

## Facts

- Founded: 2026
- HQ: San Francisco
- YC batch: S26
- Backers: Y Combinator
- Funding: unknown
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Software engineering teams
- Pricing model: unknown

## The eleven build decisions

1. **Build interface:** Dashboard for connecting GitHub repositories and configuring setup scripts/environment variables.
2. **Runtime and tenancy:** Multi-tenant SaaS providing isolated cloud sandboxes/development environments.
3. **Tool and integration strategy:** Integrates with GitHub, Slack, Linear, iMessage, and Sentry; supports MCP servers.
4. **Knowledge and data strategy:** Live sync with GitHub repositories; ports over local sessions and memories.
5. **Autonomy and human-in-the-loop:** Supports autonomous execution with approval gates for sensitive actions.
6. **Governance and enterprise controls:** unknown
7. **Pricing model:** unknown
8. **GTM motion:** unknown
9. **Moat thesis:** Workflow lock-in via cloud-ported local development setups and integrated QA tools.
10. **Open-source posture:** Proprietary
11. **Task horizon:** Multi-step workflow (minutes to hours) from request to reviewed code.

## Analysis

- **Agent capability depth:** Agents can read/edit code, run test suites, start dev servers, verify work in a browser, and open GitHub PRs.
- **Weaknesses:** Early stage with no visible traction beyond YC launch.
- **Trajectory:** Moving toward "cloud software factories" by simplifying the deployment of tokens and agent ergonomics.
- **M&A:** none visible
