# Blitzy

**Thesis (one line):** An autonomous software development platform that reverse-engineers enterprise codebases to build, refactor, and modernize software end-to-end.

## Facts

- Founded: 2023
- HQ: Cambridge, MA
- YC batch: none
- Backers: Northzone (lead), PSG, Battery Ventures, Jump Capital, Morgan Creek Digital, Defiant, Flybridge, Link Ventures, NFX, Picus Capital, Venture Guides, Liberty Mutual Strategic Ventures, Erie Strategic Ventures, BAL Ventures
- Funding: $200M+ total; last round $200M on May 5, 2026
- Valuation: $1.4B (May 2026)
- Revenue/ARR: unknown
- ICP: Global 2000 enterprises with large codebases
- Pricing model: Tiered platform fees plus metered usage per line of code

## The eleven build decisions

1. **Build interface:** Natural language prompts via a Workspace; IDE used only for final refinements.
2. **Runtime and tenancy:** Deployable six ways, including black box on-premises.
3. **Tool and integration strategy:** Connects to GitHub.
4. **Knowledge and data strategy:** Knowledge Base that reverse-engineers codebases into a graph of dependencies and architectural decisions; live sync with code changes.
5. **Autonomy and human-in-the-loop:** Agentic SDLC where agents build 80% of the roadmap; human engineering guide completes final 20% for production.
6. **Governance and enterprise controls:** unknown
7. **Pricing model:** Platform fees (Concept Validation $50k/2mo, Structured Pilot $250k/6mo, Enterprise $500k+/yr, Transformation $10M+/yr) plus metered usage ($0.10/line ingested, $0.20/line generated).
8. **GTM motion:** Sales-led (structured pilots and enterprise terms).
9. **Moat thesis:** Proprietary "System 2 Thinking" at inference and 27+ patents.
10. **Open-source posture:** Proprietary; offers self-host/on-prem options.
11. **Task horizon:** Long-horizon; agents can "think" and cooperate for hours or run for days.

## Analysis

- **Agent capability depth:** Agents execute the full SDLC from scoping to runtime validation. They reverse-engineer existing code to map dependencies and deliver compiled, tested PRs.
- **Weaknesses:** Requires human intervention for the final 20% of production-ready code.
- **Trajectory:** Expanding capabilities in "System 2 Thinking" and hiring PhDs to solve complex problems at inference.
- **M&A:** none visible
