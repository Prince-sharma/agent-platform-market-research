## The eleven build decisions

1. **Build interface:** Code (Python, .NET, Go) and declarative YAML config
2. **Runtime and tenancy:** Vendor multi-tenant SaaS (Foundry) and self-hosting
3. **Tool and integration strategy:** MCP Registry and proprietary connector library
4. **Knowledge and data strategy:** Built-in RAG and Agent Skills for domain-specific knowledge bases
5. **Autonomy and human-in-the-loop:** Approval gates via human-in-the-loop control and checkpoints
6. **Governance and enterprise controls:** Built-in observability via OpenTelemetry and governance controls
