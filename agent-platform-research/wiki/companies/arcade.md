# Arcade

**Thesis (one line):** Authorization and secure action layer for agents — delegated OAuth, tool execution, audit logging; consolidating the agent tool supply chain via Smithery.

## Facts

- Founded: 2024
- HQ: San Francisco, CA
- YC batch: none
- Backers: SYN Ventures (Series A lead), Laude Ventures (seed), Morgan Stanley and Wipro (strategic), Neotribe
- Funding: $72M total: $12M seed (2025) plus $60M Series A (Jun 2026)
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Fortune 500 and enterprise AI agent developers
- Pricing model: Free tier; Team $25/mo plus $0.10/auth event plus $0.01/tool call (Sep 2026)

## The eleven build decisions

1. **Build interface:** Code (SDKs, tool definitions)
2. **Runtime and tenancy:** Vendor multi-tenant SaaS (Arcade Cloud)
3. **Tool and integration strategy:** MCP plus proprietary toolkits: 130+ tools across 25 toolkits (Sep 2026); Smithery registry
4. **Knowledge and data strategy:** Live sync with systems of record via authorized connectors
5. **Autonomy and human-in-the-loop:** Approval gates and runtime guardrails for agent actions
6. **Governance and enterprise controls:** Default-on audit logs (Mar 2026), delegated authorization (OAuth 2.0/API keys), user verification
7. **Pricing model:** Subscription plus per-auth-event and per-tool-call usage
8. **GTM motion:** PLG self-serve plus sales-led
9. **Moat thesis:** Authorization lock-in plus distribution via Smithery MCP registry
10. **Open-source posture:** Proprietary platform
11. **Task horizon:** Multi-step workflow (secure tool execution)

## Analysis

- **Agent capability depth:** Delegated OAuth/API-key authorization, tool execution, and audit logging so enterprise agents can act on production systems
- **Weaknesses:** Registry-neutrality questions after acquiring Smithery (Aug 2026)
- **Trajectory:** Consolidating the agent tool supply chain: authorization, tool registry, and distribution
- **M&A:** Acquired Smithery (Aug 5, 2026)
