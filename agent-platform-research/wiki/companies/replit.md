# Replit

**Thesis (one line):** An AI agent platform enabling software creation from natural language, promoting "vibe coding" to make app development accessible to everyone.

## Facts

- Founded: 2016
- HQ: Foster City, United States
- YC batch: none
- Backers: Georgian Partners (lead), Coatue, Craft Ventures, Andreessen Horowitz, G Squared, Prysm Capital, Y Combinator, Accenture Ventures, Okta Ventures, Databricks Ventures
- Funding: $922M total; $400M Series D (2026-03-11)
- Valuation: $9B (2026-03-11)
- Revenue/ARR: $150M annualized revenue (September 2025, reported by company)
- ICP: Individual builders, students, designers, small business owners, and enterprise teams (PMs, Designers, Ops, Finance, HR, Legal)
- Pricing model: Subscription tiers plus usage-based credits

## The eleven build decisions

1. **Build interface:** Natural language (English), chat, and a shared workspace with live cursors.
2. **Runtime and tenancy:** Multi-tenant SaaS; Enterprise plan offers single-tenant environments.
3. **Tool and integration strategy:** Proprietary platform for building apps, websites, and software; Enterprise includes organization-wide integrations.
4. **Knowledge and data strategy:** Built-in database with rollback up to 28 days for certain plans.
5. **Autonomy and human-in-the-loop:** Agent handles execution behind the scenes; users can scope work in "Plan mode" and optimize via Lite, Economy, or Power modes.
6. **Governance and enterprise controls:** SSO/SCIM, governance, data controls, static outbound IPs, and usage limits/budgets.
7. **Pricing model:** Tiered subscriptions: Starter ($17-$20/mo), Core ($95-$100/mo), Pro ($100/mo). Usage-based "effort-based pricing" for Agent; credit packs from $100 to $950.
8. **GTM motion:** PLG self-serve (upgrade directly in-product) and sales-led for custom enterprise deals.
9. **Moat thesis:** Workflow lock-in via an integrated environment where the agent handles the full lifecycle from imagination to execution.
10. **Open-source posture:** Proprietary.
11. **Task horizon:** Multi-step workflow; Agent performs reasoning work and writes code to build full applications.

## Analysis

- **Agent capability depth:** The agent translates natural language into functional software, handling the execution of code and reasoning. It allows non-technical users to build apps, internal tools, and dashboards end-to-end.
- **Weaknesses:** Behavior is probabilistic and may occasionally make mistakes.
- **Trajectory:** Moving toward "vibe coding" where source code becomes an unimportant byproduct and programming is done entirely in English.
- **M&A:** none visible
