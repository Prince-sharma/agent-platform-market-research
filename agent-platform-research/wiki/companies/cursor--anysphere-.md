# Cursor (Anysphere)

**Thesis (one line):** An AI-native IDE providing autonomous code iteration and fixing to accelerate software engineering workflows.

## Facts

- Founded: unknown
- HQ: unknown
- YC batch: none
- Backers: Thrive Capital (lead), Andreessen Horowitz, Accel, DST Global
- Funding: $2.3B Series D (2025-11-13)
- Valuation: $9.9B (verified 2026-09-09)
- Revenue/ARR: Over $500M ARR (verified 2026-09-09)
- ICP: Individual developers and enterprise software engineering teams
- Pricing model: Tiered subscription (per user/month)

## The eleven build decisions

1. **Build interface:** IDE with natural language interaction and "YOLO mode" for autonomous iteration
2. **Runtime and tenancy:** Vendor multi-tenant SaaS; includes Cloud Agents
3. **Tool and integration strategy:** MCPs, skills, hooks, and a team marketplace for internal rules and plugins
4. **Knowledge and data strategy:** Shared team context for cloud agents and automations; prompts and code context sent to LLM providers
5. **Autonomy and human-in-the-loop:** Autonomous code iteration, testing, and fixing; includes "Auto" mode to balance intelligence and cost
6. **Governance and enterprise controls:** RBAC (repository, model, and MCP access controls), audit logs, SCIM provisioning, SAML/OIDC SSO, and SOC2 Type II/GDPR compliance
7. **Pricing model:** Per seat: Hobby (Free), Individual ($20/mo), Teams Standard ($40/user/mo), Teams Premium ($120/user/mo), Ultra ($200/mo), and Custom Enterprise
8. **GTM motion:** PLG self-serve for Hobby/Individual/Teams; sales-led for Enterprise
9. **Moat thesis:** Workflow lock-in via AI-native IDE integration and team-wide shared context
10. **Open-source posture:** Proprietary
11. **Task horizon:** Multi-step workflow (autonomous code iteration, testing, and fixing)

## Analysis

- **Agent capability depth:** Agents perform autonomous code iteration, testing, and fixing. They provide agentic code reviews via Bugbot and utilize cloud agents with shared team context for automations.
- **Weaknesses:** unknown
- **Trajectory:** Moving toward a vision where source code "melts away" and users can generate 2,000-line PRs from minimal pseudo code.
- **M&A:** none visible
