# Voker

**Thesis (one line):** An analytics platform for AI agents that uses production signals to automatically generate and refine agent instructions.

## Facts

- Founded: unknown
- HQ: Los Angeles
- YC batch: S24
- Backers: Y Combinator

- Pricing model: unknown

## The eleven build decisions

1. **Build interface:** SDK (drop-in swap) and AI-guided setup prompts
2. **Runtime and tenancy:** multi-tenant SaaS
3. **Tool and integration strategy:** proprietary SDK wrapping AI provider SDKs
4. **Knowledge and data strategy:** captures events, sessions, and users from production interactions
5. **Autonomy and human-in-the-loop:** automated generation of "Smart Skills" based on user corrections and frustration
6. **Governance and enterprise controls:** unknown
7. **Pricing model:** unknown
8. **GTM motion:** PLG self-serve (AI-assisted onboarding)
9. **Moat thesis:** data gravity via automated annotations (intents, corrections, resolutions)
10. **Open-source posture:** proprietary
11. **Task horizon:** multi-step workflow (observes sessions and interactions)

## Analysis

- **Agent capability depth:** Provides visibility into LLM interactions and automatically improves agent performance via self-improving instructions.
- **Weaknesses:** Early stage with limited public information on enterprise governance and pricing.
- **Trajectory:** Moving toward a closed-loop system where analytics directly drive agent optimization (Smart Skills).
- **M&A:** none visible
