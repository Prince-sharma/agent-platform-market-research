# BotCity

**Thesis (one line):** Governance and orchestration platform for Python automations and AI-generated scripts; the control plane for enterprise "shadow automation."

## Facts

- Founded: 2018, Brazil (Lorhan Caproni CEO, Gabriel Archanjo CTO)
- HQ: San Francisco, CA, with São Paulo entity
- YC batch: W22
- Backers: Four Rivers (Series A lead, Sep 2025), YC, Lew Cirne, SoftBank LatAm funds, Astella, Upload Ventures
- Funding: $12M Series A (Sep 25, 2025) plus R$15M earlier Brazilian round (Dec 2021)
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: IT and security leaders governing enterprise Python automations and AI agents
- Pricing model: No public pricing; free community tier; enterprise quote-based

## The eleven build decisions

1. **Build interface:** Code (Python) plus low-code Studio; supports AI-generated scripts
2. **Runtime and tenancy:** SaaS cloud plus local and on-prem deployment options
3. **Tool and integration strategy:** Proprietary BotCity framework with computer vision for GUI automation; no MCP focus evident
4. **Knowledge and data strategy:** Automations act directly on target systems; no RAG
5. **Autonomy and human-in-the-loop:** Governance framework with approvals; scheduling, queues, monitoring
6. **Governance and enterprise controls:** Audit trails, vulnerability scanning, library authorization, Sentinel endpoint monitoring agent
7. **Pricing model:** Quote-based enterprise; free community Maestro tier
8. **GTM motion:** Sales-led with community PLG entry
9. **Moat thesis:** Governance and orchestration lock-in for Python automations; LatAm enterprise beachhead
10. **Open-source posture:** Proprietary platform (Python-based); local/on-prem deployment
11. **Task horizon:** Multi-step scheduled automations (minutes to hours); persistent scheduled bots

## Analysis

- **Agent capability depth:** Maestro (orchestration, scheduling, queues), Studio (build), Sentinel (endpoint monitoring and security) for Python automations and AI agents
- **Weaknesses:** No public pricing; RPA-heritage niche; smaller brand than UiPath in enterprise automation
- **Trajectory:** Repositioned around governing AI-generated "shadow automation," the stated Series A thesis (Sep 2025)
- **M&A:** None visible
