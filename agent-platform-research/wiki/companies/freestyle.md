# Freestyle

**Thesis (one line):** A cloud platform providing sandboxes and serverless runtimes to run and deploy code written by AI agents.

## Facts

- Founded: 2024
- HQ: San Francisco
- YC batch: S24
- Backers: Silas Capital (lead)
- Funding: $10M Series A
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Developers building coding agents and AI app builders
- Pricing model: unknown

## The eleven build decisions

1. **Build interface:** API and SDK (Web Deploy API)
2. **Runtime and tenancy:** multi-tenant SaaS (serverless runtime)
3. **Tool and integration strategy:** unknown
4. **Knowledge and data strategy:** eternal javascript object persistence (cloudstate)
5. **Autonomy and human-in-the-loop:** unknown
6. **Governance and enterprise controls:** unknown
7. **Pricing model:** unknown
8. **GTM motion:** PLG self-serve
9. **Moat thesis:** Infrastructure lock-in via specialized AI-centric deployment and persistence layers
10. **Open-source posture:** OSS components (e.g., Adorable, freestyle-auth)
11. **Task horizon:** multi-step workflow (minutes) to persistent (always-on)

## Analysis

- **Agent capability depth:** Agents can write, execute, and deploy full-stack JavaScript applications with automatic TLS and domain mapping.
- **Weaknesses:** Early development stage with a narrow focus on JavaScript/Node compatible runtimes.
- **Trajectory:** Expanding from simple sandboxes to a comprehensive "cloud for Coding Agents" including persistence and auth.
- **M&A:** none visible
