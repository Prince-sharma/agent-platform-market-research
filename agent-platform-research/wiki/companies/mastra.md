# Mastra

**Thesis (one line):** An open-source TypeScript framework for developers to build, observe, and deploy production-ready AI agents and workflows.

## Facts

- Founded: 2025
- HQ: unknown
- YC batch: W25
- Backers: Gradient, pg, YC
- Funding: $35M total, $22M Series A (2026)
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Developers and product teams building AI agents
- Pricing model: Tiered subscription (Starter, Teams) plus usage-based fees

## The eleven build decisions

1. **Build interface:** Code (TypeScript) and Studio (collaborative interface for testing and managing)
2. **Runtime and tenancy:** Vendor multi-tenant SaaS (Mastra Cloud) and self-host/dedicated VPC options
3. **Tool and integration strategy:** MCP (Model Context Protocol) and custom tool definitions
4. **Knowledge and data strategy:** Built-in memory with semantic recall, observational memory, and LibSQL/Postgres storage
5. **Autonomy and human-in-the-loop:** Typed workflows with control flow, retries, and branches
6. **Governance and enterprise controls:** RBAC, SSO, IAM, audit logs, and network policy integration
7. **Pricing model:** Platform fee plus usage (CPU time, observability events, token markup, and storage)
8. **GTM motion:** PLG self-serve via open-source framework and cloud platform
9. **Moat thesis:** Developer workflow lock-in via TypeScript-native framework and integrated observability
10. **Open-source posture:** OSS core (Apache 2.0); proprietary enterprise self-hosted features
11. **Task horizon:** Multi-step workflow and long-horizon (agents that run for days)

## Analysis

- **Agent capability depth:** End-to-end agent lifecycle including typed definition, multi-mode coordination via Harness, and "Factory" for issue-to-production software automation.
- **Weaknesses:** Early traction with no reported ARR; heavy reliance on TypeScript ecosystem.
- **Trajectory:** Rapid funding growth from $13M seed (Oct 2025) to $22M Series A (Apr 2026) amid high L2 niche demand.
- **M&A:** none visible
