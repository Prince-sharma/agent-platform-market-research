# The Context Company

**Thesis (one line):** An observability platform that detects silent failures and analyzes user behavior to improve production AI agent performance.

## The eleven build decisions

1. **Build interface:** SDK (under 10 lines of code) and dashboards
2. **Runtime and tenancy:** multi-tenant SaaS
3. **Tool and integration strategy:** Framework integrations (Vercel AI SDK, LangChain, LangGraph)
4. **Knowledge and data strategy:** Captures execution data (prompts, tool calls, results, errors)
5. **Autonomy and human-in-the-loop:** unknown
6. **Governance and enterprise controls:** unknown
7. **Pricing model:** unknown
8. **GTM motion:** PLG self-serve
9. **Moat thesis:** Data gravity through production execution logs and user intent detection
10. **Open-source posture:** Proprietary; maintains an "observatory" repository on GitHub
11. **Task horizon:** multi-step workflow (minutes)

- **Agent capability depth:** Provides full-stack visibility into agent execution, including tool calls, hallucinations, and latency.
- **Weaknesses:** Early stage with limited public information on enterprise governance and pricing.
