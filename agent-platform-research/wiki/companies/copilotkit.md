## The eleven build decisions

1. **Build interface:** Code (React SDKs, npx CLI)
2. **Runtime and tenancy:** Vendor multi-tenant SaaS, VPC, or self-host
3. **Tool and integration strategy:** MCP and proprietary AG-UI protocol
4. **Knowledge and data strategy:** Live sync with systems of record (CRM, data warehouses, tickets)
5. **Autonomy and human-in-the-loop:** Approval gates for high-value actions; human-in-the-loop inputs
6. **Governance and enterprise controls:** Audit trails, RBAC (permissions-based data access), and SLAs
7. **Pricing model:** Platform fee plus per-seat for teams
8. **GTM motion:** PLG self-serve with enterprise sales
9. **Moat thesis:** Workflow lock-in via Generative UI and AG-UI protocol
10. **Open-source posture:** OSS core; self-host option available
11. **Task horizon:** Multi-step workflow (minutes)

- **Weaknesses:** Heavy reliance on React ecosystem for primary frontend value proposition.
