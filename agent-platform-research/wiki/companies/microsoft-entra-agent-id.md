# Microsoft Entra Agent ID

**Thesis (one line):** An enterprise identity and security framework providing authentication, authorization, and governance for nonhuman AI agent identities at scale.

## Facts

- Founded: unknown
- HQ: unknown
- YC batch: none
- Backers: unknown
- Funding: unknown
- Valuation: unknown
- Revenue/ARR: unknown
- ICP: Enterprise organizations deploying autonomous or assistive AI agents
- Pricing model: Bundled with Entra suite / Agent 365

## The eleven build decisions

1. **Build interface:** Dashboards (Microsoft Entra admin center/Azure portal) and code-first (Microsoft Graph API)
2. **Runtime and tenancy:** Multi-tenant SaaS
3. **Tool and integration strategy:** Proprietary connectors via Microsoft Entra ID platform and specialized OAuth flows
4. **Knowledge and data strategy:** Live sync with Entra ID directory for identity and access management
5. **Autonomy and human-in-the-loop:** Enforces approval gates via sponsorship, owner assignments, and consent for scopes
6. **Governance and enterprise controls:** RBAC, audit trails, agent identity blueprints, and time-bound access packages
7. **Pricing model:** Bundled with Entra suite / Agent 365
8. **GTM motion:** Sales-led / bundled distribution
9. **Moat thesis:** Distribution via Microsoft 365/Azure ecosystem and deep integration with existing enterprise identity gravity
10. **Open-source posture:** Proprietary
11. **Task horizon:** Persistent (always-on identity management for agents)

## Analysis

- **Agent capability depth:** Enables agents to securely authenticate, impersonate identities via blueprints, and access APIs/services using specialized tokens.
- **Weaknesses:** High dependency on the Microsoft ecosystem; licensing complexity across various Entra plans.
- **Trajectory:** Expanding toward full lifecycle management of "agent sprawl" and tighter integration with Zero Trust principles for AI.
- **M&A:** none visible
