# Airtop

**Thesis (one line):** A browser automation cloud that compiles natural language into deterministic code for reliable, cost-efficient AI agent execution.

- Pricing model: Tiered monthly subscription plus credits

## The eleven build decisions

1. **Build interface:** Natural language to compiled code (Agent Builder)
2. **Runtime and tenancy:** Vendor multi-tenant SaaS (Cloud runtime)
3. **Tool and integration strategy:** Proprietary connector library and browser-based interaction
4. **Knowledge and data strategy:** Live sync with systems of record via integrations and APIs
5. **Autonomy and human-in-the-loop:** Human-in-the-loop teaching loop (watch and correct to compile)
6. **Governance and enterprise controls:** SOC 2 Type 2 report, audit trails (video replay), and vault for API keys
7. **Pricing model:** Platform fee plus usage (credits)
8. **GTM motion:** PLG self-serve (Free and Starter tiers)
9. **Moat thesis:** Purpose-built browser infrastructure and deterministic code compilation
10. **Open-source posture:** Proprietary
11. **Task horizon:** Multi-step workflow (minutes)

## Analysis

- **Agent capability depth:** Agents navigate websites, portals, and apps to perform tasks like lead enrichment, invoice reconciliation, and competitive intelligence.
- **Weaknesses:** Dependence on browser-based interaction can be fragile compared to native APIs if site structures change rapidly.
- **Trajectory:** Moving toward a "build once, run forever" model by converting LLM-heavy planning into low-cost, deterministic runtime code.
- **M&A:** none visible
