# Browserbase

**Thesis (one line):** Managed headless-browser cloud for AI agents; sessions, stealth proxies, and context APIs that make web automation reliable.

## Facts

- Founded: 2024
- HQ: San Francisco, CA
- YC batch: none
- Backers: Notable Capital (Series B lead, Jun 2025), CRV and Kleiner Perkins (Series A co-leads, Nov 2024), Okta Ventures
- Funding: $67.5M over 4 rounds: $21M Series A (Nov 12, 2024) plus $40M Series B (Jun 17, 2025)
- Valuation: $300M (Jun 2025)
- Revenue/ARR: unknown
- ICP: Developer teams and AI companies building web-automation agents
- Pricing model: Subscription plus usage (Developer $20/mo, Startup $99/mo, $0.10-0.12/browser-hr, Search $7/1k, Fetch $1/1k)

## The eleven build decisions

1. **Build interface:** Code (SDKs) plus natural language (Stagehand) plus no-code (Director, Jun 2025) plus plain-language Agents (Jun 2026)
2. **Runtime and tenancy:** Multi-tenant SaaS; enterprise tier
3. **Tool and integration strategy:** Proprietary platform APIs (Sessions, Context, Search, Fetch) plus OSS SDKs and framework integrations
4. **Knowledge and data strategy:** Infrastructure; Context API caches browser state; no RAG
5. **Autonomy and human-in-the-loop:** Enables fully autonomous agents; infrastructure itself has no approval gates
6. **Governance and enterprise controls:** SOC 2 Type II, HIPAA; enterprise RBAC and audit
7. **Pricing model:** Tiered subscription plus metered browser-hours, searches, fetches, proxies
8. **GTM motion:** PLG self-serve plus sales-led enterprise
9. **Moat thesis:** Category leadership, Stagehand OSS distribution, stealth and anti-detect IP
10. **Open-source posture:** Platform proprietary; Stagehand SDK OSS (MIT); no platform self-host
11. **Task horizon:** Multi-step (minutes to hours); managed Agents extend to longer horizons (2026)

## Analysis

- **Agent capability depth:** Managed browser cloud: sessions, stealth proxies, captcha solving, Search/Fetch/Context APIs, observability; one-API-call Agents (Jun 30, 2026)
- **Weaknesses:** Usage costs compound at scale; Kernel undercuts on price/performance (per Kernel's own comparison, Aug 2026)
- **Trajectory:** From raw browser infrastructure toward managed agent endpoints (Director Jun 2025; Agents Jun 2026)
- **M&A:** None visible
