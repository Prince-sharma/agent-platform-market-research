# Tasklet

**Thesis (one line):** A cloud agent OS for knowledge work that delegates end-to-end business processes across SaaS tools via persistent, autonomous AI agents.

## Facts

- Founded: 2020 (as Shortwave), 2025 (as Tasklet)
- HQ: San Francisco
- YC batch: S26
- Backers: Union Square Ventures (lead), Lightspeed (lead), Y Combinator, Jeff Dean, Patrick Collison, John Collison, Oleka Capital
- Funding: $33M total, $13M bridge round, 2026-07-31
- Valuation: $175M (previous round date unknown)
- Revenue/ARR: $5M ARR (as of 2026, high confidence)
- ICP: Business teams and knowledge workers
- Pricing model: Usage-based (pay for work, not seats)

## The eleven build decisions

1. **Build interface:** natural language
2. **Runtime and tenancy:** vendor multi-tenant SaaS (isolated cloud environments per agent)
3. **Tool and integration strategy:** proprietary connector library (3,000+), MCP, and HTTP API
4. **Knowledge and data strategy:** live sync with systems of record and agent-wide memory
5. **Autonomy and human-in-the-loop:** approval gates; guardrails
6. **Governance and enterprise controls:** RBAC, SOC 2 compliant, spend caps, centralized billing
7. **Pricing model:** platform fee plus usage (pay for work, not seats)
8. **GTM motion:** PLG self-serve (Free to start)
9. **Moat thesis:** workflow lock-in, integrations, data gravity (memory)
10. **Open-source posture:** proprietary
11. **Task horizon:** persistent (always-on)

## Analysis

- **Agent capability depth:** Agents autonomously execute multi-step workflows (e.g., CRM enrichment, financial matching, meeting prep) using APIs, code sandboxes, and cloud browsers.
- **Weaknesses:** unknown
- **Trajectory:** Moving from a standalone agent tool to comprehensive enterprise AI infrastructure for managing corporate knowledge and business processes.
- **M&A:** none visible
